You can open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Safari, Brave):

1. Double-click `index.html` in file explorer:
   `C:\Users\kumar\.gemini\antigravity\scratch\abdulelah-portfolio\index.html`
2. Or serve locally with any HTTP server:
   ```bash
   # Using Python 3
   python -m http.server 3000
   ```
   Then open `http://localhost:3000` in your browser.

## 🌐 Deploying Online (Free & Instant)

### Option 1: GitHub Pages
1. Create a repository on GitHub (e.g., `abdulelah-portfolio`).
2. Push all files in this directory.
3. In repository **Settings** → **Pages**, select branch `main` and root `/`.
4. Your website will be live at `https://<username>.github.io/abdulelah-portfolio`.

### Option 2: Netlify / Vercel
- Drag and drop the `abdulelah-portfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or deploy via Vercel for instant free global hosting.
